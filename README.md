# Library Management System
A consolo-based Python application for managing library books and members.
## Features
- Add new books
- Add new membrs 
- Issue books to members 
- Return issued books 
- View all books and members 
- Search for a book using its ID
- View library statistics 
- Save and load data using a JSON file
## Technologies Used
- Python 3
- Object-Oriented Programming (OOP)
- JSON file handling
## Project Structure
- 'main.py' - Runs the menu-driven application
- 'book.py' - Contains the Book class
- 'member.py' - Contains th Member class
- 'library.py' - Contains library operations 
- 'data_manager.py' - Saves and loads data
- 'library-data.json' - Stores books and members
## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run: 
```bash
python main.py
```
4. Choose an option from the menu
