# Project Statement
## Problem Statement
Managing books and member records manually can be slow and may lead to mistakes. It is difficult to track which books ar available, issued, or returned.
## Project Scope 
The Library Management System is a console-based Python application that manages books, library members, book issuing, book returns, searching, and reports. The application saves data in a JSON file so information is retained after the program closes.
## Target Users 
- Librarians 
- Students 
- Small educational libraries
## High-Level Features 
- Add and view books 
- Add and view members
- Issue and return books 
- Search books by ID
- View library reports 
- Save and load data
